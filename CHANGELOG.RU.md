# История изменений

Подробная информация доступна в [документации](https://citeck-ecos.readthedocs.io/ru/latest/%D0%A0%D0%B5%D0%BB%D0%B8%D0%B7%D1%8B.html)

## [2025.8] - 2025-09-XX

### Добавлено

- Журналы. Режим отображения плитками
- Журналы. Панель предварительного просмотра данных с возможностью настройки виджетов
- Виджет "Диаграмма Ганта" для визуализации плана работ по проекту в виде временной шкалы
- Компонент Select journal. Возможность выбора рабочих пространств для поиска и агрегации данных
- Справочники. Унифицирован дашборд для типа данных Справочник, для справочников "Контрагенты" и "Юридические лица" определены специальные дашборды
- Настройка скрытия кнопки «Создать» в левом меню
- Настройка скрытия кнопки создания новой записи в журналах
- Улучшения в базе знаний

### Исправлено

- Карточка Контрагента. На форме редактирования самопроизвольно очищается поле "Полное наименование"
- Вычисляемое значение возвращается некорректно для массивов ассоциаций
- Ошибка при выполнении действия "Скачать все документы"
- На форме редактирования рабочего пространства дублируется текст ошибки
- При возникновении IllegalStateException в процессе в окне ошибки стал отображаться стек
- Не изменяется значение свойства hidden у чекбокса, если менять его в действии логики
- Чекбокс с двумя состояниями true/false при переключении в false имеет состояние null
- Пункт меню список - не фильтруются типы данных, можно добавить любые
- При редактировании Дашборда в разделе администратора создается новый Дашборд
- Не работает кнопка изменения размера поля комментария/примечания

## [2025.5] - 2025-08-01

### Добавлено

- Кроссплатформенный лончер для быстрого локального разворачивания Citeck как с демонстрационными данными, так и без них.
- Клиент 360 - в карточке контрагента во вкладках отображаются консолидированные данные из модулей платформы, такие как история взаимодействия по сделкам и договорам, технической поддержке.
- Канбан доска: подсчет суммы в колонках, применение шаблона для названия канбан-карточек.
- В пользовательской задаче в форме по умолчанию добавлено поле «Комментарий».
- LinkFormatter: добавлены варианты конфигурации открытия ссылки по форматтеру.
- Улучшения в Оргструктуре.
- Улучшения в WYSIWYG редакторе.
- TableForm: добавлена возможность выбора значения из справочника.

### Исправлено

- Onlyoffice. Неверное отображение курсора при редактировании файла. 
- Menu. Редактирование меню для рабочего прострранства по умолчанию.
- Рабочие пространства. Отображение шаблонов
- Рабочие пространства. Навигация в браузере.
- Журнал. Редактирование значений в ячейках. 
- Канбан-доска. Отображение полного имени Ответственного.
- Проблема медленной загрузки задач BPMN при применении фильтра.

## [2025.1.7] - 2025-06-24

### Добавлено
- Виджеты для мобильной версии.
- Оргструктура доступна в рабочем пространстве Справочники.
- Новые поля в общедоступных справочниках.

### Исправлено

- Обновлены права на редактирование в базе знаний и виджете HTML.
- Адаптивность для виджета "Приветствие".
- В компоненте Date/Time реализована локализация Ru/Eng.
- Браузерная навигация (назад, вперед) в рабочих пространствах.
- Откат транзакции для закрытого соединения.

## [2025.1.3] - 2025-05-26

### Добавлено

- Рабочие пространства- отдельные области Citeck для совместной работы пользователей над определенным набором функциональных возможностей, документов, файлов, процессов.
- Корпоративный портал - раздел Citeck для сотрудников компании, который объединяет различные инструменты, информацию и сервисы в одном месте.
- Обновленный интерфейс журналов позволяет адаптивно управлять отображением данных в таблице в зависимости от высоты экрана устройства пользователя.
- Функциональные модули теперь распределены по рабочим пространствам.
- Поддержка рабочих пространств в меню 
- Обновлен модуль Поручения: добавлена канбан-доска для отслеживания прогресса выполнения. Модуль работает в составе рабочих пространств.
- Сбор анонимной статистики с использованием сервиса [Umami](https://umami.is/docs)i. Сервис не собирает и не хранит персональные данные, избегая необходимости использования файлов cookie.
- При создании типа данных добавлена возможность указывать, что текстовый атрибут является уникальным. 
- BPMN редактор. В уведомление добавлена возможность отправки писем-встреч в календарь пользователя.
- BPMN редактор. В пользовательской задаче добавлена возможность устанавливать срок задачи вручную или через выражение.
- В журнале «Темы» добавлено действие для применения темы.
- Профиль пользователя. Права на просмотр и редактирование данных.
- Отправка тестового сообщения при запуске микросервиса уведомлений.
- Поиск  по документам, людям (пользователям), рабочим пространствам.
- Представление данных в виде списка. Представление можно использовать для отображения, например, списка новостей, базы знаний, перечисления товаров или оборудования.
- Библиотека документов в рабочем пространстве. Возможность создать пустой допкумент, таблицу, презентацию для совместной работы
- ColoredFormatter: добавлено отображение в виде точки.
- В компонент Оргструктура добавлена возможность динамически задавать корневую группу (через скрипты в зависимости от условий на форме), от которой начнется отображение иерархии при выборе группы/пользователя.
- React JS обновлен до версии 18.3 

### Исправлено

- Проблема с функциональностью генерации шаблонов после обновления версии микросервиса трансформации.
- Модуль Service desk. Неверный расчет SLA и дат, отображения поля "Резолюция".
- Журнал "Меню". Ошибка загрузки действий.
- Модуль "Договоры". Ошибка в проссе дополнительного соглашения.
- Модуль "Договоры". Ошибка прав.
- Шаблоны уведомлений. Фильтр по колонке не работает.
- Библиотека документов. Ссылка для скачивания документа ведет на саму карточку
- Виджет "Документы". Ошибка при загрузке нескольких файлов.
- Виджет "Документы". Нет превью для файлов типа txt, html, xml, json, yaml.
- Системные артефакты не добавляются в ecos-app микросервис.
- BPMN. Ошибка обработки транзакции промежуточного события (catch event).
- Профиль пользователя. Обязательность заполнения полей.
- Оргструктура. Удаление родительской группы.
